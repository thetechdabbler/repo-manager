# Utility commands

Small, read-only commands for inspecting projects and the tool itself.

## `projects`

List every saved profile and mark the active one.

```bash
repo projects
```

--8<-- "reference/_generated/projects.md"

## `version`

Print the installed version.

```bash
repo version
```

--8<-- "reference/_generated/version.md"

## `help`

Print a one-screen manual: every command, the repository states, the changes-column
legend, and the exit codes. Useful at the point of use, in the terminal.

```bash
repo help
```

--8<-- "reference/_generated/help.md"

!!! tip "Per-command help"
    Every command also has its own `--help` (for example `repo <project> update --help`),
    generated by the CLI with the full, current flag list.
